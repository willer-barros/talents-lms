# Talents 🎓

Plataforma de Gestão de Aprendizagem (LMS) construída com **NestJS** e **React**.

## Stack

| Camada | Tecnologia |
|--------|-----------|
| Backend | NestJS, TypeScript, PostgreSQL, Prisma ORM |
| Frontend | React, TypeScript, Vite, Tailwind CSS |
| Autenticação | JWT, Bcrypt |
| Observabilidade | @nestjs/observe |
| Package Manager | pnpm |

## Funcionalidades

- 📚 Criação e gestão de cursos, módulos e lições
- 👥 Gestão de usuários e perfis (admin, instrutor, aluno)
- 📝 Atribuições, quizzes e avaliações
- 📊 Dashboard com métricas de progresso
- 🔐 Autenticação e autorização por roles
- 📁 Upload de materiais (vídeos, PDFs, arquivos)

## Pré-requisitos

- Node.js ≥ 20
- pnpm ≥ 12
- PostgreSQL ≥ 15
